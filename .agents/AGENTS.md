# Project Rules

- **Review Changelog Before Starting**: Every time a user asks you to perform a task, you MUST read the `CHANGELOG.md` file located at `c:\Single Screen\CHANGELOG.md` first. Review the past mistakes, architectural changes, and bug fixes documented there to ensure you fully understand the context of the project and do not repeat past mistakes.
- **No Automatic Deploy or Git Push**: NEVER deploy to hosting (Firebase/etc.) and NEVER push to git automatically. Only build and test locally (e.g. localhost) unless the user explicitly asks to deploy or push to git.
